# Report 接口本地调试切换说明

> 当前仓库内所有接口**默认对接生产环境**（`process.env.BASE_URL`）。
> 开发 / 联调时，需要把用到的接口临时切回本地测试地址（`12.18.xx.xx`），**提交代码前务必切回生产**。

---

## 切换方法（通用）

每个 `src/services/*.ts` 里都保留了两份 request 实例（生产 & 测试），互为注释：

```
// 生产环境使用
const xxxRequest = createRequest(`${process.env.BASE_URL}/xxx`, { timeout: 1000 * 60 });

// 测试环境使用
// const xxxRequest = createRequest(`http://12.18.1.36:8085/oms/xxx`, { timeout: 1000 * 60 });
```

切本地：**解注释**测试那一份，**注释**生产那一份。
切回生产：反过来即可。**commit / 合入前必须切回生产。**

## 切换指引（快速自查）

改动接口后，提交前执行：

```bash
# 查看当前是否还有"活动"的 12.18 测试地址（应为空 / 只在注释里）
grep -rn "^const .*createRequest(\`http://12\.18" src --include=*.ts --include=*.tsx

# 查看所有 12.18 引用是否都被注释
grep -rn "12\.18" src --include=*.ts --include=*.tsx
```

第一条命令有输出 = 还有活动测试地址，**未切回生产，禁止提交**。
第二条命令的输出应全部以 `//` 或 `` ` `` 开头（注释内）。
